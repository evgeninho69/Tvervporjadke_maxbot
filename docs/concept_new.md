Дизайн-концепт и MVP Мини-аппа «Тверь в порядке»

Платформа: Mini App (WebView внутри мессенджера).
Цель: Быстрый и удобный канал связи жителей Твери с городской администрацией для решения коммунальных, дорожных и социальных проблем, а также для предложений.

1. Минимальный функционал (MVP)

Для запуска первой рабочей версии (MVP) необходим следующий набор функций:

1.1. Авторизация и профиль

Бесшовная авторизация: Приложение автоматически получает ID пользователя, его имя и (если разрешено) номер телефона из мессенджера.

Экран профиля: Базовая информация и настройка уведомлений (получать пуши/сообщения от бота при смене статуса заявки).

1.2. Создание обращения

Выбор категории: Дороги (ямы, светофоры), ЖКХ (мусор, вода, отопление), Благоустройство (парки, вандализм), Предложения (идеи для города).

Текстовое описание: Поле для ввода сути проблемы (с ограничением до 1000 символов).

Прикрепление медиа: Загрузка фото/видео (камера или галерея, ограничение в MVP — до 3 фото).

Геолокация:

Кнопка «Определить мое местоположение» (GPS).

Мини-карта, где можно поставить пин (булавку) вручную.

Резервное текстовое поле для ввода адреса (если GPS не работает).

1.3. Мои обращения (История)

Список всех отправленных заявок пользователя.

Статусы заявок: «На модерации», «В работе», «Решено» (с фото-отчетом от администрации), «Отклонено».

2. UX (Пользовательский опыт)

Пользователь не должен тратить больше 1 минуты на отправку жалобы.

Сценарий «Идеальный путь» (Happy Path):

Пользователь пишет боту /start или нажимает кнопку в меню мессенджера -> Открывается Mini App.

На Главном экране он видит большую кнопку «+ Сообщить о проблеме».

Выбирает категорию из списка (иконка + текст).

Открывается форма:

Пишет: "Открытый люк на тротуаре".

Нажимает скрепку -> делает фото люка.

Нажимает «Где это?» -> карта автоматически ставит точку по координатам, пользователь нажимает «Подтвердить».

Жмет кнопку «Отправить».

Появляется экран успеха: "Спасибо! Ваше обращение №1234 отправлено".

Когда люк закрывают, бот в мессенджере присылает сообщение: "Ваше обращение решено. Фото результата по ссылке".

3. UI (Пользовательский интерфейс)

3.1. Визуальный стиль

Цветовая палитра: * Фон: Светло-серый (для визуального разделения карточек) или адаптивный под Dark Mode мессенджера.

Акцентный цвет (Кнопки): Глубокий синий (символизирует Волгу, надежность) или Бордовый/Красный (цвет герба Твери, но в приглушенном современном оттенке).

Цвета статусов: Желтый (в работе), Зеленый (решено), Серый (модерация).

Шрифты: Системные шрифты (San Francisco для iOS, Roboto для Android). Это обеспечит максимальную скорость загрузки и нативность.

Элементы: Скругленные углы (corner radius 12-16px) у карточек и кнопок. Крупные элементы управления (удобно нажимать на ходу).

3.2. Структура экранов (Wireframes)

Экран 1: Главная (Home)

Шапка: Приветствие ("Здравствуйте, Иван!") и логотип/герб Твери (минималистичный).

Основное действие: Огромная плавающая или центральная кнопка с иконкой мегафона или плюса: «Новое обращение».

Блок "Мои последние заявки": Свайп-карусель или список из 2-3 последних заявок со статусами (чтобы не переходить в другой раздел без нужды).

Нижнее меню (Tab bar): [Главная] | [Мои обращения] | [Профиль].

Экран 2: Форма подачи (Scrollable Form)

Шаг 1: Категория (Выпадающий список или сетка иконок).

Шаг 2: Что случилось? (Многострочное текстовое поле с подсказкой "Опишите проблему").

Шаг 3: Фото (Блок с пунктирной рамкой: "+ Добавить фото. Максимум 3"). При добавлении появляются миниатюры с крестиком для удаления.

Шаг 4: Адрес (Кнопка "Указать на карте". При клике открывается модальное окно с Яндекс.Картами или 2GIS, после выбора адреса он пишется текстом).

Подвал: Фиксированная внизу экрана (sticky) кнопка «Отправить обращение» (становится активной только если заполнены обязательные поля).

Экран 3: Карточка обращения (Детали)

Заголовок: Номер заявки и дата.

Статус: Большой цветной бейдж (например, 🟢 РЕШЕНО).

Суть: Текст пользователя.

Фото проблемы: Галерея пользователя.

Официальный ответ: Блок выделенный другим фоном. Текст ответа администрации ("Ремонт произведен силами МУП...") + Фотография решенной проблемы.
